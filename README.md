# 🎓 Sistema LMS (Learning Management System)

Este é um sistema de gerenciamento de aprendizado (LMS) desenvolvido com **Streamlit**. Ele permite gerenciar **cursos**, **alunos** e **matrículas** de forma simples e eficiente.

---

## 🚀 Funcionalidades

### 📘 Cadastro de Cursos
- Cadastro de novos cursos com:
  - Código do curso
  - Nome do curso
  - Descrição do curso
- Exibe uma mensagem de sucesso ao cadastrar

### 🧑‍🎓 Cadastro de Alunos
- Cadastro de alunos com:
  - CPF
  - Nome completo
  - E-mail
- Verifica se o aluno já está cadastrado

### 📝 Matrícula de Alunos
- Matrícula de alunos em cursos
- Verificação se o aluno já está matriculado no curso
- Registro da data e hora da matrícula

### 📚 Listar Cursos
- Exibe todos os cursos cadastrados com:
  - Código do curso
  - Nome do curso
  - Descrição

### 👨‍🏫 Listar Alunos
- Exibe todos os alunos cadastrados com:
  - CPF
  - Nome completo
  - E-mail

### 📜 Histórico de Matrículas
- Exibe o histórico completo de matrículas com:
  - Data e hora da matrícula
  - Nome do aluno
  - Nome do curso

---

## 🛠️ Tecnologias Utilizadas
- **Python**
- **Streamlit** – Interface do usuário
- **Datetime** – Registro de datas e horários
